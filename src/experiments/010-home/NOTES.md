# 010 · Home —— 设计笔记

> **这个实验在回答什么**
> 如果首页本身就是这个产品，输入框悬在正中，会怎么样？

## 我在探索什么

008 和 009 都默认「打开就是对话」。010 换一个前提：**打开是首页，对话是首页之后的事。**

参考的是操作系统那一类产品的感觉：安静、明亮、不抢注意力。首页只有四样东西 —— 问候、一句话、几个建议、一个输入框。

## 和 008 / 009 的三个区别

1. **输入框在首页是悬在正中的**，不贴在底部。进入对话之后才沉到底部。这是「OS 级输入框」最直接的样子
2. **Agent 状态是一行微小指示器**，不是面板。做完自动收起成「4 步」，点开才看得到
3. **右侧是 Context 而不是 Workspace**，回答的是「它用了什么」，不是「它产出了什么」。默认收起

## 视觉

- 底 `#f8f7f5` 极浅暖灰
- **整屏没有彩色强调**，只有一个墨色 `#17171a`。焦点靠边框和阴影的细微变化表达
- 问候语用英文大写排在大字号上（44px，字距 -0.038em），和周围的中文形成层次
- 不用传统 Loading。状态是一个会呼吸的小圆点 + 文字

## 已知取舍

- Context 面板的数字是 Mock，不做真实的引用统计
- 首页问候按本地时间切换，只有四档
