# B5 · Desktop —— 设计笔记

> **这个实验在回答什么**
> 如果 Agent 不是一个网页，而是一个活在桌面上的存在，会怎么样？

---

## 一、核心概念

### 一句话

> **Agent 不是你要打开的页面，而是住在你桌面上的一样东西。**

前四个实验都还是「打开一个界面」。这一次，Agent **一直在那儿**：
它平时缩在右下角安静地呼吸；你给它一件事，它**开一个窗口**去做；
你可以把它最小化去做别的事，它在后台接着干；干完了，它**弹一张卡片**给你；
需要你拍板的时候，它**自己变形**提醒你。

### 三个层次

| 层 | 是什么 | 回答什么 |
|---|---|---|
| **① 桌面本身** | 一个地方，不是一个页面。环境光随 Agent 状态微微变化 | 它在哪 |
| **② Agent 本体** | 右下角常驻的方块。呼吸、变形、脉冲 | 它现在怎么样 |
| **③ 任务窗口** | 一个任务 = 一个窗口 | 它在干什么 |

### 最关键的映射：**一个任务 = 一个窗口**

```
给它一件事  →  开一个窗口
最小化      →  Agent 在后台继续干
干完了      →  弹一张卡片
需要拍板    →  本体变形 + 开一个确认窗口
```

**这是聊天记录永远表达不了的东西。** 聊天里没有「最小化」——你只能看着它转圈，或者关掉页面走人。

## 二、Agent 本体：整个实验的核心

它是一个 **58px 的方块**，靠**形状**说话，不靠图标：

| 状态 | 方块变成 | 里面的核心 |
|---|---|---|
| **idle** | 圆角方块（20px） | 一个点在缓慢呼吸 |
| **thinking** | **变成圆形** | 一个点沿着圆周匀速绕行 |
| **working** | 圆角收紧到 14px | **一个点分裂成三个**，各自漂移，节奏不同 |
| **waiting** | **圆形 + 实心边框 + 脉冲** | 一个点，1.1s 快速呼吸 |
| **done** | 圆角 + 绿色边框 | 一个点在弹跳 |
| **error** | — | — |

再加一层：**方块内部从底部往上填充 = 总体进度**。不看窗口也知道干到哪了。

**这不是一个图标，是一个有身体的符号。** 圆角从 20 → 50% → 14 的变化，比换一个图标更能让人感到"它现在是什么心情"。

## 三、桌面环境光

**整个桌面的色调会随着 Agent 的状态微微变化。**

| 状态 | 环境色 |
|---|---|
| idle | 中性灰蓝 `#6c7a8c` |
| thinking | 淡紫 `#7a6ea8` |
| working | 冷青 `#3f8fa8` |
| waiting | 琥珀 `#c4811f` |
| done | 柔绿 `#4f8a63` |

四层渐变色叠在一起交叉淡入（`opacity` 过渡 1.1s），**所以不看 Agent 也能感觉到它在忙。**

这是桌面独有的自由度 —— 一个网页没有"环境"，一个桌面有。

## 五、可以真的操作的七件事

| 操作 | 会发生什么 |
|---|---|
| **拖动窗口标题栏** | 真的能拖，位置按桌面百分比记，窗口跟着走 |
| **点任意窗口** | 置顶（z-index 会加） |
| **标题栏的 – / ×** | 最小化 / 关闭 |
| **点 Dock 里的图标** | 窗口回到屏幕中央并置顶 |
| **点右下角的 Agent 本体** | 唤起命令面板（Spotlight 式） |
| **⌘K / Ctrl+K** | 同上 |
| **点通知卡片** | 关掉 |

还有一个：**在命令面板里真的能打字**，回车会用你的指令重跑整段演示。

> 演示运行期间，**两个窗口是同时在跑的** —— 这才是桌面能表达、聊天不能表达的东西。

## 六、时间线（27 秒）

| t | 事件 |
|---|---|
| **1.6** | 本体 → thinking |
| **2.0** | 命令面板浮现在桌面中央 |
| **2.4–4.0** | 打字机打入指令 |
| **4.05** | 回车。面板收起，桌面上方浮出「当前目标」 |
| **4.3** | **窗口 A「整理季度数据」开出**（左） |
| **5.2** | **窗口 B「检查依赖更新」开出**（右） —— 两个任务同时跑 |
| **10.6** | 窗口 A 完成（标题栏出现 ✓） |
| **10.9** | **通知卡片滑入**右上角 |
| **12.0** | **窗口 A 被最小化** —— 缩成一个小点飞进 Dock |
| **12.5** | 窗口 B 卡住 → 标题栏变 ⚠ |
| **13.0** | **本体 → waiting（变成圆形 + 脉冲）**，整个桌面泛起琥珀色 |
| **13.4** | 确认窗口弹出 |
| **17.6** | 批准 → 确认窗口关闭 |
| **18.1** | 窗口 B 重跑（进度归零又爬满） |
| **21.7** | 窗口 B 完成 |
| **22.1** | 本体 → done → 22.9 回到 idle |
| **23.2** | 第二张通知：「全部完成 · 2 个任务」 |

**节奏曲线：** 安静 → 开两个窗口同时忙 → 一个先完成 → 最小化 → **卡住（全桌变琥珀）** → 拍板 → 收尾。

| | 001 Bench | 002 One Line | 003 Terminal | 004 Chronicle | **005 Desktop** |
|---|---|---|---|---|---|
| 本质问题 | **排版** | **编码** | **信息密度** | **时间** | **存在感与主动性** |
| Agent 是什么 | 一个列表 | 一条线 | 一个进程 | 一条时间轴 | **一个住在桌面上的东西** |
| 界面的边界 | 铺满屏幕 | 一条线 | 一个窗口 | 一张图纸 | **一整个桌面** |
| 并行怎么表达 | 依次排开 | 飞白 | 四条进度条 | 三条泳道 | **两个窗口同时开着** |
| 能不能走开 | 不能 | 不能 | 不能 | 不能 | **能 —— 最小化，它在后台接着干** |
| 谁先说话 | 用户 | 用户 | 用户 | 用户 | **Agent 会自己浮上来（waiting）** |

**五句话概括：**
> 001 研究怎么把 Agent 的工作**排**出来。
> 002 研究怎么把它**编码**进去。
> 003 研究怎么让它**看起来真的在发生**。
> 004 研究它**把时间花在哪了**。
> 005 研究它**怎么和你共处一室**。

## 八、实现要点

| 关注点 | 做法 |
|---|---|
| 窗口进度 | `fill` 是插值动画，但**只有「整行 / 整项」变化时才 setState** —— 表格逐行出现，清单逐条打勾 |
| 拖动 | 位置存**桌面百分比**，拖动时按容器像素换算 —— 所以换屏幕尺寸窗口不会跑偏 |
| 用户操作与剧本共存 | 用户操作直接改同一份 `disc` 然后 `commit()`；剧本走 rAF 循环改它。两边是同一份状态，不会打架 |
| 环境光 | 四层渐变叠加，靠 `opacity` 交叉淡入 —— 直接改颜色是没法过渡的 |
| 时钟 | 用的是**真实时间**，不是假数据 |

### 已知取舍

- **窗口不能改大小**。真 OS 可以，这里收益不高。
- **Dock 只显示当前会话的任务**，不保留历史。
- **确认窗口的按钮点了就关**，不真的改变剧本走向（剧本是固定的）。
- **移动端只做了「不崩」**：缩小、隐藏目标条。
