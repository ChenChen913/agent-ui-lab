# A5 · Bubble —— 设计笔记

> **这个实验在回答什么**
> 如果 Agent 用最传统的那套聊天语法来表达自己呢？
> 头像一个，昵称一个，气泡一条，时间在底下。谁都看得懂。

## 我在探索什么

A1 到 A4 都在**刻意避开气泡**。它们用的是「现代 AI 产品」那一套：无气泡、大留白、消息就是文字块。

气泡之所以存在是有原因的：**它让「谁说了什么」变得毫无歧义**，而且十亿人已经会读了。

这个实验反过来问：**把 Agent 塞进这个人人都会用的语法里，会不会反而更好用？**

## 走错过一次，记在这里

第一版做成了**微信电脑版的三栏布局**：深色导航条 + 会话列表 + 会话区，
还给气泡配了微信的浅绿 `#95ec69`。

那是把「交互方式」和「产品外壳」搞混了。要学的是前者：
头像、昵称、气泡、时间。微信的导航条和会话列表跟这个实验没有关系，
它们只是微信这个产品的其他部分。

重做之后只有会话本身，没有侧栏，没有会话列表，没有导航条。

## 核心观点

> **两个不对称，是这个界面真正在说的话。**

| | 用户 | Agent |
|---|---|---|
| 宽度 | 窄，内容多宽就多宽（上限 62%） | **几乎占满整列** |
| 底色 | 深绿 `#0e8a5f`，白字 | 白色面板，细边，极轻的阴影 |
| 装什么 | 一句话 | **过程、列表、引用、产物** |

**Agent 的话天生比用户的话长，而且结构更复杂。** 把它塞进一个跟用户一样宽的气泡里，
内容就会被挤成一条细长条。给它一块面板，它才装得下。

第一版两边都是气泡，看起来整齐，但 Agent 的那条一长就难读。

## Agent 面板里装什么

| 块 | 用在哪儿 |
|---|---|
| 段落 | 结论、说明 |
| 有序 / 无序列表 | 三条结论、能做的事（行内支持 `**加粗**`） |
| 引用块 | 需要单独提醒的一句话 |
| **执行过程** | 浅灰底的三个步骤，带状态点、耗时 |
| 文件卡片 | 最后产出的那个文件 |

**执行过程放在面板内部**，不另开面板。这是「一个 Agent 说的话」和
「一个 Agent 做的事」在同一个地方。

## 首屏那条是初始状态，不是演示的第一拍

参考图里的第一条就是 Agent 的自我介绍：你好 + 我能帮你做这些 + 一个加粗的清单。

这一条必须是**打开就能看到**的，不能等播放键。定时拍子只在演示时跑，
空状态永远等不到它。踩过一次，记下来。

## 已知取舍

- 「我」的头像是灰色圆形加一个人形图标，没有做真实头像上传
- 执行过程不能手动折叠，它是跟着状态走的
- 文件卡片可以点，但没有真的下载
- 引用块、表格、代码块只实现了引用块，其余留到以后

## 下次想试什么

- [ ] **表格和代码块**进面板之后，宽度和滚动的处理
- [ ] **语音条**：一种完全不同的消息形态，Agent 能不能用它
- [ ] **引用回复**：长按某条消息引用它再追问，这样上下文就有出处了
