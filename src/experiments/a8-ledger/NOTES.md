# A8 · Ledger —— 设计笔记

> **这个实验在回答什么**
> 一个搜索型 Agent 的答案，凭什么可信？

## 2026-09 重写：右栏改成页边注

原来的「衬线答案 + 右侧来源栏」跟 A3 的双栏结构太像——都是固定右栏。
这一版换成学术排版的**页边注**（Tufte sidenote）：

- 正文占中间 660px 一列，编号是上标；
- 出处卡片浮在正文右侧 232px 的页边空白处，用 CSS grid 让卡片和
  引用它的那一段**齐平**——眼睛不用离开正在读的那一行；
- 悬停编号，页边那张卡亮；悬停卡片，正文角标亮。

骨架差异靠「齐平」这两个字，不靠配色。

## 刻意保留的一段分歧

最后一段是「需要注意的一处分歧」：Linear 一路主张收成收件箱一次看一件，
Cursor 一路主张并排摊开。两份来源没有给对方让路，界面也不替 Agent 选——
可信的前提是不掩饰证据强度的差异。
