# A4 · Mission Control —— 设计笔记

> **这个实验在回答什么**
> 同时派五个 Agent 出去，界面除了并排五个聊天框还能是什么？

## 2026-09 重写：表格换成卡片流

第一版做成了深色 telemetry 表格，被评价为「不知道做了个什么东西」。
问题出在表格本身没有视觉层级——每一行都是等宽文字，看不出谁重要。

这一版换成**卡片流**（参考 Antigravity 的 Manager Surface 与 Windsurf 的
Command Center）：一张卡一个 agent，四件事全在卡上——

- 左边 4px 状态色带：跑着是蓝，等你拍板整张泛琥珀，落地是绿；
- 最新活动一行等宽字，跟着剧本滚；
- 细进度条 + 耗时 + ACU 成本，成本两位小数在跳；
- 悬停才出现的暂停 / 掐掉按钮——不抢视线，但一直在。

撞上依赖冲突的那张卡把自己挪到底下那条「待你拍板」里。那一块是这一页
唯一的交互高潮，不埋在网格里。

## 视觉：Linear 的暗色系统

深蓝黑 #0b0f14 + 一层发丝线 + 只有一个彩色（indigo #5e6ad2）。
状态色是例外，且刻意只在「需要你看一眼」的那一刻出现。
圆角一律很小，边框比阴影多。

## 引擎

进度是逐帧爬的（不是一拍跳一格），所以集群看着是活的。
循环停止条件写死：剧本走完、且没有 agent 在跑。用户插手之后
剧本让位，改由 400ms 心跳接着跑——心跳在派新 agent 时会重挂。
