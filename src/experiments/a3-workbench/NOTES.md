# A3 · 过程与产物 —— 设计笔记

> **这个实验在回答什么**
> 过程是结果的记录，还是结果的草稿？

## 2026-09 重构：合并了原 014（Settle）

原 A8 的观点——**过程是产物的草稿**——并进了这一版：

- Workspace 里每一段右上角有来源角标（来自第 N 步），悬停步骤或段落两边互相高亮；
- 做完的步骤可以撤掉，文档里属于它的段落一起塌陷——看少掉什么，才知道每一步值多少；
- 剧本里加了一段演示：撤掉「对比信息」，表格和风险提示一起消失，再放回来；
- live 模式里同样的交互都可以点（X 撤 / ↺ 放回来）。

聊天 + 双层结构不变。原 A8 的独立页面取消，它的页边标记语言在这里变成了角标。

## 我在探索什么

008 把「聊天」这一层做扎实了。009 问的是下一层：**Agent 产出的东西，应该在哪里？**

在聊天界面里，报告是最后一条消息。它会被后面的对话顶上去，复制出去才能用。这一版让产物有自己的位置。

## 核心结构：三层，但中央永远是主角

| 区域 | 内容 |
|---|---|
| 左侧 208px | Agent 名称 + Online 状态、新任务、历史任务、设置 / 知识 / 工具 / 模型 |
| 中央 | 任务名、对话、**可展开的 Activity**、Composer |
| 右侧 400px | Workspace：报告、表格、代码在这里预览 |

两个面板都有明确分界，但中央永远占最大面积。Workspace 可以整个关掉，关掉就回到纯聊天。

## Activity 面板

这是整个设计的重点。默认只显示一行：

> ◌ 正在执行 4 个步骤 · 预计很快完成

点开才是一条**带连接线的竖向步骤流**：

> ● 搜索网络 · 23 条结果
> ● 阅读资料 · 12 篇
> ● 对比信息 · 3 处出入
> ◌ 生成报告

只展示对用户有意义的工具调用，不暴露内部思维链。

## 关键时刻

报告**边写边长**出现在右边的面板里，最后一节还在流式输出的时候，前面几节已经可以读了。这是「产物有自己的位置」这句话最直接的样子。

## 视觉

- 底 `#f6f6f4` 暖中性，面板纯白
- 强调色是墨绿 `#2e6b52`，只给 Agent 标识、进度点和完成态
- 步骤流用连接线表达顺序，不用数字
