# A7 · Weight —— 设计笔记

> **这个实验在回答什么**
> 同一块界面，面对一句话和二十个项目，应该给出同样分量的过程吗？

## 2026-09 重写：列表换成仪表 + 日志流

原来还是竖列表（分量刻度贴在行上），骨架和 A6 是同一种。这一版换成
**上半区读数、下半区过程**的仪器结构：

- 上半区一块半环表（SVG 弧 + dasharray + 指针），指针指到哪就是
  这件事值多少过程，旁边是大号读数；
- 下半区等宽日志流，一行一行刷——表越大，刷得越密；
- 第三个任务跑到一半，表从 34 爬到 96，日志区同时**自己撑开**
  （max-height 从 214px 过渡到撑满），这是这个模板存在的理由。

## 视觉：仪器，不是聊天软件

整页只有一种字体（等宽）、一种颜色（琥珀 #e0a33e）、圆角不超过 4px、
没有阴影。层级全靠三种灰和几条发丝线。「疑」是唯一的暖色之外，
用在它自己拿不准的地方——界面不替 Agent 掩饰不确定性。

## live

用户自己派活：按句子长度和用词粗估一个分量（「整个」「迁移」这类词
直接加分），然后按分量刷出对应密度的日志。定时器统一记录，重开全清。
