# A9 · Return —— 设计笔记

> **这个实验在回答什么**
> 用户离开 20 分钟再回来，界面上应该是什么？

## 观点

> **你不在的时候，Agent 的工作不该变成一条你没读过的长消息。**
> **它应该变成一份「你不在时发生了什么」的简报。**

**B1 到 A8 全部是「你在这儿看着它做完」。** 这是第一个有时间跨度的实验。
B5 说了「你可以走开」，但没有回答回来看到什么。

## 四层，按你需要介入的程度排

| 层 | 内容 |
|---|---|
| **需要你决定** | 1 到 2 条，浮在最上面，琥珀色 |
| **我替你决定了** | 一行一条，每条带「为什么」，可以点开 |
| **可以忽略的** | 收成一行计数 |
| **时间带** | 底部一条细线，上面几个点标着值得看的时刻 |

## 最要紧的交互

**「我不在的时候，你替我做了哪些决定？」**

点开任意一条，看到的是：当时摆着的两个选项、它选了哪个（高亮）、
为什么这么选，以及一个「下次这种事问我」，点下去当场生效。

其中一条是刻意的：**「没有订阅那份付费报告」**，理由是
「涉及花钱的事我不替你决定」。这是整个实验里我最想让人看到的一条：
**替你决定和该问你之间，有一条线。**

## 时间带

底部那条细线是 09:38 到 10:01。**你离开的这 23 分钟是有长度的**，
上面几个点对应简报里的条目，可以直接点。

## 已知取舍

- 简报的条目是写死的，不是从真实步骤里归纳出来的
- 「下次这种事问我」只是把按钮点亮，没有真的影响后续同类判断
- 时间带上的点不能拖，只能点

## 下次想试什么

- [ ] **「问我」这条规则真的生效**：之后再出现同类决定时，它真的会停下来问
- [ ] 简报条目的归纳**由 Agent 自己做**（哪些算「需要你」，哪些算「可以忽略」）
- [ ] 离开 3 天再回来，简报的形态应该不一样
