# 014 · Settle —— 设计笔记

> **这个实验在回答什么**
> 过程和结果，是两个东西，还是同一个东西的两个阶段？

## 观点

> **过程不是结果旁边的一份记录，过程是结果的草稿。**

009 让过程和产物同时存在，但它们是**两个分开的面板**：左边 Activity，右边报告。
014 说：它们应该是同一个东西。

## 界面里没有过程面板

只有一份正在长出来的文档。左页边那一列是它做过的事（搜索 / 阅读 / 提取 / 对比），
每一段和产出它的那一步之间有一条细线连着。

**每做完一步，那一步不是消失，而是变成文档的一部分：**

| 那一步 | 变成了文档里的什么 |
|---|---|
| 搜索 | 一、候选范围 |
| 阅读 | 二、三个维度的差异 |
| 提取 | 那张对比表 |
| 对比 | 那句「证据不足，先不下结论」 |

## 最要紧的交互是反向的

**撤掉一个来源，看文档少掉什么。**

点左边任何一个标记，靠它产出的段落整块划掉，保留删除线，可以恢复。
这是「过程即草稿」最直接的证明：如果过程真的只是记录，删掉它不应该影响文档；
但它影响了，说明它就是文档的来路。

## 已知取舍

- 过程和段落的映射是写死的，不是推出来的
- 撤掉一个来源只是把段落划掉，没有真的重新生成
- 表格只有三行，没有做长表格的滚动
